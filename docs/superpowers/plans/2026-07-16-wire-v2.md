# Wire v2 — Sign Provenance, Clear Deprecated Types (Roadmap Step 6) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Consult `.claude/skills/wire-protocol` — this changes the public contract.

**Goal:** Bump the wire protocol to v2 in a single hard cutover: sign `SubnetID` (closing B7), derive the federation discount from the signed origin subnet instead of the mutable hop count (closing B2), and remove the deprecated `port_class` field and reserved `ScoreEntry` type (C1).

**Architecture:** A breaking wire change (`SchemaVersion` 1→2, gossip topic `…/v0`→`…/v2`, domain strings `-v1`→`-v2`). The signed message gains `SubnetID` so a relay cannot rewrite the diversity/home-subnet key. The report-path federation discount becomes a binary cross-federation-boundary rule keyed on the signed `SubnetID`, so scoring no longer trusts the mutable `OriginTrace` length (which remains only for the feedback-loop guard, trace-cap, and dedup).

**Tech Stack:** Go 1.22, Ed25519 event/vote signing (`internal/identity`), libp2p gossipsub, `pkg/proto` wire contract.

## Global Constraints

- Go module `github.com/JoeRu/federloom`, Go 1.22. Conventional Commits.
- **Hard cutover — no dual-version support.** No external deployments exist; do NOT add v1/v2 compatibility shims, dual-listen, or version negotiation. A v1 node simply cannot interoperate with v2 (different signed bytes + topic) — that is expected.
- **This is a breaking `pkg/proto` change** (wire-protocol skill): bump `SchemaVersion` to 2 and add a `CHANGELOG.md` entry. Signatures INTENTIONALLY change — the equivalence bar is NOT byte-identity; it is "v2 verifies, a v1-formatted (SubnetID-omitting) signature fails."
- **No pretend-anonymisation:** `IP` stays cleartext (spec §9). No hashing.
- **Sign the right bytes:** `SubnetID` is added to BOTH the event and vote signed messages; `VerifyEventSig` covers it. `OriginTrace` stays UNSIGNED and is used only for the feedback-loop guard / trace-cap / dedup (not scoring).
- **Discount keyed on signed subnet:** the report-path federation discount applies once iff the (now-signed) `e.SubnetID` canonically differs from the node's own `FederationSubnet`, for non-anchored reporters (anchored remain exempt). Same-subnet direct events are undiscounted, exactly as today.
- Removal-only for `port_class` / `ScoreEntry` — no code outside `pkg/proto` (+ tests) should reference them after this; a grep gate enforces it.
- Full gate: `go build ./... && go vet ./... && gofmt -l internal/ pkg/ cmd/ test/` (empty) + unit + `-race` + `-tags adversarial` + `-tags integration`.

// TestFederationDiscountKeyedOnSubnet: a non-anchored event from a DIFFERENT
// subnet is discounted once; a same-subnet event is not; hop count no longer
// matters (an event with a long OriginTrace but same subnet is undiscounted).
func TestFederationDiscountKeyedOnSubnet(t *testing.T) {
	n, _ := testNode(t) // node's FederationSubnet is "" (default) via config.Defaults
	// Cross-subnet stranger event → discounted (weight lower than same-subnet).
	crossIP, sameIP := "198.51.100.30", "198.51.100.31"
	n.ProcessRemote(transport.ReceivedEvent{
		Event: proto.Event{IP: crossIP, Reason: "ssh-probe", ReporterID: "strangerA", SubnetID: "othersubnet", Timestamp: time.Now(), OriginTrace: []string{"strangerA"}},
		From:  "strangerA", Subnet: "home",
	})
	// Same-subnet stranger event (SubnetID == node's "" ) with a LONG OriginTrace.
	n.ProcessRemote(transport.ReceivedEvent{
		Event: proto.Event{IP: sameIP, Reason: "ssh-probe", ReporterID: "strangerB", SubnetID: "", Timestamp: time.Now(), OriginTrace: []string{"strangerB", "h1", "h2", "h3"}},
		From:  "strangerB", Subnet: "home",
	})
	cross, _ := n.GetScore(crossIP)
	same, _ := n.GetScore(sameIP)
	// Same-subnet (undiscounted, full stranger weight) scores higher than the
	// cross-subnet (discounted) event, DESPITE the long OriginTrace on the
	// same-subnet one — hop count no longer drives the discount.
	if !(same.Score > cross.Score) {
		t.Errorf("same-subnet (%v) should outscore discounted cross-subnet (%v); hop count must not matter", same.Score, cross.Score)
	}
}

		discount := n.cfg.Trust.FederationDiscount
		if discount <= 0 || discount > 1 {
			discount = 0.5
		}
		weight *= discount
	}
