# Disputes / Anti-Trust Votes (Roadmap Step 5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An operator who whitelists an IP as `shared-vote` federates a signed dispute; nodes apply it as a diversity-weighted negative vote that lowers the recomputed score and, past a dispute-diversity floor, undoes a materialised federated block.

**Architecture:** A dispute travels as a `proto.Event` with `Kind:"vote"` (domain-separated signing), reusing the whole transport/dedup/anti-spoof path. `ProcessRemote` routes votes to a dispute path that subtracts a diversity-weighted contribution (a pure `reputation.ApplyDispute`, tracking a SEPARATE `DisputeSubnetsSeen` set). A materialised-block registry lets a diverse-enough dispute `Unblock` a federated block and suppress re-materialisation — never touching a local anchored block. The `EvidenceAggregate` carries `dispute_subnets` so the Step-4 recompute closes the loop.

**Tech Stack:** Go 1.22, libp2p gossip, Ed25519 event signing, BadgerDB, ipset/nftables/crowdsec sinks.

## Global Constraints

- Go module `github.com/JoeRu/federloom`, Go 1.22. Conventional Commits.
- **A dispute is an `Event{Kind:"vote"}`** — reuses transport/signing/dedup; NOT overloading `Reason` (attack taxonomy); a vote has `Reason:""`.
- **Report signing byte-for-byte unchanged:** `SignEvent`/`VerifyEventSig` select the message by `Kind` — reports keep `"federloom-event-v1"|IP|Reason|Timestamp|ReporterID`; a vote signs `"federloom-vote-v1"|IP|Timestamp|ReporterID`. Existing event tests must pass unchanged.
- **Diversity-weighted (§4.4 Sybil defense):** disputes are weighted by distinct disputing subnets × trust; a single-subnet or stranger dispute-flood cannot materially lower a score or trip unblock. Report-diversity (`SubnetsSeen`) and dispute-diversity (`DisputeSubnetsSeen`) are NEVER conflated.
- **Local sovereignty (Leitprinzip 1/8):** a remote dispute NEVER unblocks a local anchored block, never mutates a `local-only` whitelist; every parameter locally overridable. `local-only` entries are never emitted as votes.
- **Enforcement safety:** the only new enforce effect is `sink.Unblock` (the safe direction); disputes never create a block. The Step-4 local-block path and anchored-corroboration backstop are unchanged.
- **Groups-empty (E2) invariant** preserved in `RecordFromEvidence`.
- Backward-compat: no shared-vote entries / no votes ⇒ behaviour byte-for-byte as today.
- Full gate: `go build ./... && go vet ./... && gofmt -l internal/ pkg/ cmd/ test/` (empty) + unit + `-race` + `-tags adversarial` + `-tags integration`.

```go
// ApplyDispute subtracts a diversity-weighted negative vote from rec's score
// (spec §4.4). A dispute from a NEW disputing subnet counts full; a repeat from
// an already-counted disputing subnet is damped by diversityRepeat (reusing the
// D mechanic on a SEPARATE DisputeSubnetsSeen set — dispute diversity is never
// conflated with report diversity). Strangers' disputes are cap-bounded so a
// stranger dispute-flood cannot clear a score. The score floors at 0. Pure.
func ApplyDispute(rec store.ScoreRecord, obs Observation, now time.Time, halfLife time.Duration, disputeWeight, strangerCap, diversityRepeat float64) store.ScoreRecord {
	if !rec.LastSeen.IsZero() {
		rec.Score = DecayScore(rec.Score, rec.LastSeen, now, halfLife)
	}
	firstFromSubnet := obs.Subnet != "" && !containsString(rec.DisputeSubnetsSeen, obs.Subnet)
	divFactor := 1.0
	if obs.Subnet != "" && !firstFromSubnet {
		divFactor = diversityRepeat
	}
	// Proportional reduction so it cannot drive the score negative; scaled by the
	// current score so a near-zero IP isn't over-disputed.
	reduction := obs.Trust * disputeWeight * (rec.Score / 100) * divFactor
	if !obs.Anchored {
		// Strangers share one capped bucket, mirroring the report stranger cap.
		remaining := strangerCap - rec.DisputeContrib
		if remaining < 0 {
			remaining = 0
		}
		if reduction > remaining {
			reduction = remaining
		}
	}
	rec.DisputeContrib += reduction
	rec.Score -= reduction
	if rec.Score < 0 {
		rec.Score = 0
	}
	if firstFromSubnet {
		rec.DisputeSubnetsSeen = append(rec.DisputeSubnetsSeen, obs.Subnet)
	}
	rec.LastSeen = now
	return rec
}
```

func (e *Engine) RecordDispute(ip, reporterID string, trust float64, subnet string, anchored bool) (float64, int, error) {

	if err != nil {
		return 0, 0, fmt.Errorf("reputation: get %q: %w", ip, err)

		return 0, 0, fmt.Errorf("reputation: put %q: %w", ip, err)
	}

// maybeUnblockDisputed unblocks a materialised FEDERATED block for ip once
// distinct disputing subnets reach the floor, and suppresses re-materialisation.
// It NEVER touches a block that was not materialised by this node (local
// anchored blocks are absent from n.materialised) — local sovereignty.
func (n *Node) maybeUnblockDisputed(ip string, disputeSubnets int) {
	if disputeSubnets < n.cfg.DisputeUnblockMinSubnets {
		return
	}
	n.matMu.Lock()
	_, wasMaterialised := n.materialised[ip]
	n.disputed[ip] = struct{}{} // suppress future re-materialise regardless
	delete(n.materialised, ip)
	n.matMu.Unlock()
	if !wasMaterialised {
		return // never Unblock something we didn't materialise (local block, etc.)
	}
	if err := n.sink.Unblock(ip); err != nil {
		log.Printf("node: dispute-unblock %s: %v", ip, err)
		return
	}
	log.Printf("node: dispute-unblocked federated block %s (dispute_subnets=%d)", ip, disputeSubnets)
	n.obs.RecordUnblock(ip)
}

func TestSybilDisputeFloodCannotClearBlock(t *testing.T) {
	// Single-subnet flood: 50 disputes, all from "sybil" → below the subnet floor.
	n, sink := matDisputeNode(t)
	n.MaterialiseForTest("203.0.113.80", store.ScoreRecord{Score: 90, LastSeen: time.Now()}, 4)

		if ip == "203.0.113.80" {
			t.Fatalf("single-subnet dispute flood must NOT unblock a materialised block")

	}
	found := false

		if ip == "203.0.113.81" {

		}
	}
	if !found {
		t.Errorf("diverse anchored disputes should unblock; unblocked=%v", sink2.unblocked)
